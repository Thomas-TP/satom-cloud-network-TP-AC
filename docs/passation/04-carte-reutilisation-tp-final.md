# Carte de réutilisation : TP final -> ce qui existe déjà

Pour chaque sprint du sujet (https://hackmd.io/@Formateur/rJOiAHwCMg), ce que nous avons déjà, où le trouver, et ce qu'il reste à écrire. Les noms de scènes (`mNNx`) renvoient à `video/shoot/mNNx.py` : chaque fichier est la suite exacte de clics faits dans la console, avec les valeurs saisies. Les mesures sont dans `docs/modules/mNN/tests.txt` et dans le chapitre `docs/modules/mNN.md`.

**Écarts du sujet à faire confirmer** (voir les questions) : région Zurich (nous : Stockholm), plages `10.0.0.0/16` (nous : `10.20.0.0/22`, `10.21.0.0/24`), domaine `.example` (nous : un vrai sous-domaine), adresses documentation pour les passerelles client (nous : routeurs simulés avec adresse publique).

Le TP réseau n'a **aucune** de ces briques : dépôt avec branche protégée et pull requests, pipeline GitHub Actions (étapes 1 à 7), OIDC GitHub vers AWS, `cfn-lint`, `cfn-guard`/`checkov`, SonarQube, Semgrep, gitleaks, Trivy, SBOM, OWASP ZAP, k6, Security Hub, GuardDuty, AWS Config, X-Ray, KMS, WAF, ADR, journal et indicateurs DORA. Elles sont à construire. Le squelette `tp-final/satom-leman-portail/` en pose la structure et une pipeline de départ.
